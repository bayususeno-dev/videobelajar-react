# videobelajar-react

## Description

A video-based learning platform website built with React JS as part of a web development bootcamp mission. The project focuses on building reusable UI components, passing data through props, and implementing responsive layouts.

## Features

- Homepage
- Login page
- Registration page
- Reusable UI components
- Responsive layout for desktop, tablet, and mobile
- Form interactions and basic input validation

## Technologies

- React JS
- JavaScript
- Vite
- CSS
- React Router

## Project Structure

Main project folders:

- `src/components/` → Reusable UI components
- `src/components/atoms/` → Basic UI elements such as buttons, inputs, and logos
- `src/components/molecules/` → Combined components such as form fields and course cards
- `src/components/organisms/` → Larger UI sections such as navigation bars and forms
- `src/pages/` → Homepage, login, and registration pages
- `src/assets/` → Images, icons, and other assets
- `src/styles/` → CSS files
- `src/App.jsx` → Main application component
- `src/main.jsx` → Application entry point
